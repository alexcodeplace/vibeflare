actions/upload-artifact while its existing browser-evidence step references it.
The candidate replaces the blocked action with bounded, SHA256-reconstructable

on failed tests. No browser test, runner, required job, resource budget, or
release acceptance is removed. The original failure remains recorded, and
the new complete source run must demonstrate job startup and actual execution.

## Source-bound evidence receipt hardening

The restored in-log PNG frame transport now binds every browser manifest to
the actual checked Git HEAD, GitHub run ID and attempt; missing or spoofed
Actions source identity fails before success output. A new negative test
demonstrates rejection, and path/symlink checks prohibit dereferencing files
outside the bounded browser result tree. PNG bytes remain reconstructed from
checksum-verified frames only when the original failure generated them.
